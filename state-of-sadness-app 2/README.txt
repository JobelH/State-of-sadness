STATE OF SADNESS - installable app (PWA)

1. Upload ALL files in this folder to any free static host (Netlify Drop, Cloudflare Pages, GitHub Pages).
   Keep them together in the same folder. It must be served over https.
2. Open your site on a phone:
   - Android (Chrome): menu > Install app / Add to Home screen
   - iPhone (Safari): Share > Add to Home Screen
   - Desktop (Chrome/Edge): install icon in the address bar
3. To publish to Google Play / App Store later, paste your site address into pwabuilder.com.

To update: replace index.html, then change CACHE='state-of-sadness-v1' in sw.js to v2 so phones refresh.
